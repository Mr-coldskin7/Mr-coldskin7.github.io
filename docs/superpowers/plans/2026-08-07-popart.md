# Pop-art halftone background implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a pure-CSS halftone-dot pop-art background to the whole site, fading at the edges and keeping the center clean.

**Architecture:** A single fixed `body::before` pseudo-element draws a repeating radial-gradient dot pattern and masks it with a radial gradient so dots are visible only near the viewport edges. Theme-aware dot colors live in CSS variables inside the existing `_sass/_themes.scss` override file.

**Tech Stack:** SCSS, Jekyll, al-folio v1.

## Global Constraints

- All changes go into the existing local override `_sass/_themes.scss`.
- No new assets or images.
- No changes to cards, buttons, headings, typography, or `_config.yml`.
- Light mode: black dots; dark mode: white dots.
- Overlay must not block clicks or scrolling (`pointer-events: none`).
- Support Safari with `-webkit-mask-image`.

### Task 2: Add the halftone overlay pseudo-element

**Files:**
- Modify: `_sass/_themes.scss`

**Interfaces:**
- Consumes: `--popart-dot-color` from Task 1.
- Produces: visual halftone dot background on `body`.

- [ ] **Step 1: Append overlay rule to the end of `_sass/_themes.scss`**

```scss
/* Pop-art halftone edge background */
body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background-image: radial-gradient(
    circle,
    var(--popart-dot-color) 1.5px,
    transparent 2px
  );
  background-size: 12px 12px;
  -webkit-mask-image: radial-gradient(
    ellipse at center,
    transparent 30%,
    black 80%
  );
  mask-image: radial-gradient(
    ellipse at center,
    transparent 30%,
    black 80%
  );
}
```

- [ ] **Step 2: Build and verify compilation**

Run:

```bash
bundle exec jekyll build --baseurl /al-folio
```

Expected: build succeeds, `_site/assets/css/main.css` (or equivalent) contains the new rule.

- [ ] **Step 3: Commit**

```bash
git add _sass/_themes.scss
git commit -m "feat: add halftone dot overlay"
```
